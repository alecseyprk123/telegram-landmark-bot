# Telegram Бот для распознавания достопримечательностей

Бот анализирует фотографии и определяет достопримечательности с помощью **Google Gemini AI**. 
Идеально подходит для путешественников и любителей истории!

## Возможности

 **Распознавание достопримечательностей** по фото
 **Статистика в реальном времени** (всего фото, за час, время работы)
 **Автоматический перебор моделей** при ошибках
 **Поддержка прокси** для работы из любой страны
 **Быстрый ответ** - анализ фото за секунды
